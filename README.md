# Mahmuda Sharmin

Extract the folder and open **index.html** in a browser. The four pages and the enclosed CV work locally. Publication and university links need an internet connection.

| File | Content |
| --- | --- |
| index.html | Profile, selected publications, and contact |
| research.html | Journal articles, manuscripts, and presentations |
| teaching.html | Teaching, mentorship, and invited talks |
| academics.html | Appointments, education, grants, and service |
| src/css/site.css | Shared layout and typography |
| assets/documents/mahmuda-sharmin-cv.pdf | Public curriculum vitae |

Edit the HTML files directly. Each page contains its own navigation and academic content. No build step or JavaScript is required.

The design is adapted from Mahmudul Morsalin Antor’s portfolio at `https://github.com/antor-morsalin/portfolio`, commit `c2a26be8a872517eef0eb9bf0e6ffad108fb9ca3`. The academic record follows the supplied November 2026 CV. The licenses in assets/fonts accompany the typefaces embedded in the PDF.
